# inventorybackend_test

Тестовое задание: серверная часть системы инвентаря и предметов (Node.js + TypeScript).
Полный текст задания — в папке [TaskDescription](TaskDescription/).

## Использование ИИ

Уточнение от HR к заданию:

> Прошу при решении не использовать ИИ.
> Нам важно, чтобы код был написан лично, так мы проверяем экспертность в JS/TS/Node.js.

На вопрос «насколько не использовать ИИ?» был получен ответ:

> Ну советоваться с ним можно, просто код писать самостоятельно на основе этой информации.

Как это соблюдается в проекте:

- Весь код написан мной вручную в WebStorm (стандартные автокомплит и подсветка синтаксиса IDE, без генерации кода ИИ).
- ИИ (Claude) использовался только как собеседник: обсуждение архитектуры, ответы на вопросы о синтаксисе и API, текстовое ревью написанного кода.
- ИИ не вносил изменения в файлы проекта и не давал готовых реализаций — замечания на ревью формулировались как описание проблемы, решение я находил сам.
- Правила работы с ИИ зафиксированы в [CLAUDE.md](CLAUDE.md).
